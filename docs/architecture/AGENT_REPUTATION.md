# Agent reputation

The statistics marketplace retains its capability-test observations and Bayesian estimates. Research records one observation per paid intent, tagged with worker, mission, capability, phase, transaction and evidence hash. Test and hire observations are distinguishable. The existing PoCP engine starts from explicit worker priors and incorporates durable verified observations into subsequent estimates.

A verified payment with an invalid or undelivered artifact remains a paid failure. Independent retrieval outages stop progress without inventing a pass or fail observation. Model-assisted report quality judgments do not become worker reliability observations.
