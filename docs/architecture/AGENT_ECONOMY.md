# Agent economy

A Groq planner proposes a small DAG. Trusted code assigns research, reporting and verification stages in dependency order. SQLite persists the mission tree, events, authorization, reservations and hashed artifacts. The web workspace reconnects through persisted SSE cursors.

Direct research runs the existing zero-HBAR workflow. Procurement preview calls two independent first-party research services for bids and x402 challenges. An authenticated approval can resume one research mission within exact caps. The existing statistics marketplace and /proof remain separate.
